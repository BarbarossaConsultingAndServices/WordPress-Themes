# Color palettes (18 total, 6 per theme)

Switch in Appearance → Editor → Styles → Browse styles. All meet WCAG AA for body text on default backgrounds (verify after heavy customization).

## nova-business (default: Indigo Trust)
- Default — white `#FFFFFF`, ink `#0F172A`, indigo `#4F46E5`, sky `#E0E7FF`, slate `#64748B`
- Navy Trust — deep navy `#0B1F3A` bg option, blue `#2563EB`
- Emerald Growth — emerald `#059669`
- Charcoal Gold — charcoal `#111827` + gold `#D4A017`
- Minimal Light — stone neutrals, single accent
- Dark Mode — `#0F172A` background, indigo lightened

## educalite (default: Emerald Campus)
- Default — white, ink `#0F172A`, emerald `#059669`, amber `#F59E0B`
- University Navy — navy `#1E3A8A` + gold
- Playful Orange — orange `#EA580C`
- Mint Fresh — mint `#ECFDF5` backgrounds
- Burgundy Classic — burgundy `#7F1D1D`
- Dark Study — dark slate + lime accent

## newsline (default: Paper + Signal Red)
- Default — paper `#FAFAF9`, ink `#111827`, red `#DC2626`
- Midnight Press — near-black + white
- Forest Gazette — deep green `#14532D`
- Ocean Times — navy `#0C4A6E`
- Sepia Print — warm sepia `#F5F0E8`
- Minimal Mono — grayscale only
