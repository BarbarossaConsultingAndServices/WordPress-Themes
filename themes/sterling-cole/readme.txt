Distinguished law-firm block theme with practice areas, attorneys, results, consultation — 100% Gutenberg, 6 palettes, auto-built demo site on activation.

== Description ==

Sterling Cole ships Home, Practice Areas (corporate/family/estates/employment/property/disputes), Our Attorneys, Case Results, About, Request a Consultation, FAQ, Chambers Gallery, Journal posts + full templates + 6 palettes (Oxblood default, Midnight Counsel, Chambers White, Hunter Brief, Steel Gavel, Burgundy Robe). Photos: bundled Pexels + Unsplash images, free to use.

== Installation ==

Upload sterling-cole.zip via Appearance > Themes > Add New > Upload > Activate. The complete demo law-firm site (pages, posts, menu, homepage) builds itself. Switch palettes in Editor > Styles.
