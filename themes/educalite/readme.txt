Modern education block theme. Courses, instructors, events, tuition, FAQ, enroll — 100% Gutenberg.

== Description ==

Educalite ships Home, Courses, About, Instructors, Events, Pricing, FAQ, Contact patterns + full templates + 6 palettes (Emerald Campus default, University Navy, Playful Orange, Mint Fresh, Burgundy Classic, Dark Study).

== Installation ==

Upload educalite.zip via Appearance > Themes > Add New > Upload. Build pages via Patterns. Switch palettes in Editor > Styles.
