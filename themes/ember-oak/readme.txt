Warm restaurant block theme. Full menu with prices, gallery, reservations, chef story, journal — 100% Gutenberg, 6 palettes, auto-built demo site on activation.

== Description ==

Ember Oak ships Home (hero cover, signature dishes, story, reviews), Menu (starters, fire mains, bowls, brunch, desserts — all with prices), About (story + chefs), Gallery, Reservations (booking placeholder, hours, groups, directions), FAQ, Journal posts + full templates + 6 palettes (Ember default, Candlelight Dark, Olive Grove, Bordeaux, Nordic Minimal, Ocean Brasserie). Photos: bundled Pexels images, free to use.

== Installation ==

Upload ember-oak.zip via Appearance > Themes > Add New > Upload > Activate. The complete demo restaurant (pages, posts, menu, homepage) builds itself. Switch palettes in Editor > Styles.
