# Nova Business demo content

Import to get a full multi-page site in 3 minutes.

1. Tools → Import → WordPress → install importer → upload `demo.wxr`.
2. Assign author, check “Download and import file attachments”.
3. Appearance → Editor → Navigation → create menu: Home `/`, About `/about/`, Services `/services/`, Pricing `/pricing/`, Blog `/blog/`, Contact `/contact/`.
4. Settings → Reading → Homepage: Home, Posts page: Blog.
5. Appearance → Editor → Styles → pick your palette.

Pages included in demo.wxr: Home (uses pattern `nova-business/home`), About, Services, Pricing, FAQ, Contact, Blog.
