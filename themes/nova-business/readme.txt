== Description ==

Nova Business is a modern Full Site Editing theme for companies, agencies and startups. Includes pre-designed pages (Home, About, Services, Pricing, Team, FAQ, Contact), templates for blog/archive/search/404, header/footer/CTA patterns, and 6 style variations (Navy Trust, Emerald Growth, Charcoal Gold, Minimal Light, Dark Mode).

No page builder, no jQuery. Just theme.json + vanilla CSS. Switch colors in Appearance > Editor > Styles.

== Installation ==

1. Download nova-business.zip from GitHub Releases.
2. Appearance > Themes > Add New > Upload > Activate.
3. Appearance > Editor to customize. Pages > Add New > Patterns to build Home/About/Services/Pricing/Contact.

== Palettes ==

Default Indigo Trust + Navy Trust, Emerald Growth, Charcoal Gold, Minimal Light, Dark Mode.
