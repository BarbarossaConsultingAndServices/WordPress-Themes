Bold fitness-studio block theme. Class schedule, trainers, membership, signup — 100% Gutenberg, 6 palettes, auto-built demo site on activation.

== Description ==

Forge Studio ships Home, Class Schedule (strength/conditioning/recovery with times), Trainers, Membership (3 plans), About, FAQ, Join, Journal posts + full templates + 6 palettes (Volt Dark default, Light Mode, Crimson Fight, Deep Ocean, Desert Iron, Raw Mono). Photos: bundled Pexels images, free to use.

== Installation ==

Upload forge-studio.zip via Appearance > Themes > Add New > Upload > Activate. The complete demo studio (pages, posts, menu, homepage) builds itself. Switch palettes in Editor > Styles.
