Adventurous travel-agency block theme with destinations/tours/deals/planning, auto-built demo site.

== Description ==

Atlas Travel ships Home, Destinations (Santorini/Kyoto/Machu Picchu/Bali/Iceland/Egypt), Guided Tours, Late Deals, About, Plan My Trip, FAQ, Postcards Gallery, Travel Journal posts + full templates + 6 palettes (Deep Teal default, Midnight Flight, Passport Minimal, Coral Reef, Alpine Air, Desert Dune). Photos: bundled Pexels + Unsplash images, free to use.

== Installation ==

Upload atlas-travel.zip via Appearance > Themes > Add New > Upload > Activate. The complete demo travel site (pages, posts, menu, homepage) builds itself. Switch palettes in Editor > Styles.
