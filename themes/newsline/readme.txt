Editorial block theme for news/magazine/blog. Hero grid, trending, newsletter, author box.

== Description ==

Newsline includes Front Page grid, Masthead About, Newsletter, Tips Contact + full templates + 6 palettes (Paper Red default, Midnight Press, Forest Gazette, Ocean Times, Sepia Print, Minimal Mono).

== Installation ==

Upload newsline.zip via Appearance > Themes > Add New > Upload. Set homepage to Front Page pattern.
